THE KEYCLOAK OUTAGE DRILL PROVES THE REAL USER CONTRACT

[04]
[ 01 / PRE-FLIGHT ]

START FROM A KNOWN-GOOD STATE

Use only synthetic realm users. Confirm BFF replicas, PostgreSQL, Keycloak readiness, alert routing, baseline login, and no active chaos resource.

EVIDENCE: baseline synthetic sign-in + lease-clean check
[ 02 / FAULT ]

PARTITION BFF → KEYCLOAK

Apply a finite, directed staging-only network partition. The controller selects BFF labels and only the Keycloak service boundary.

FAULT: 5-minute egress partition; no production namespace
[ 03 / RECOVERY ]

REMOVE FAULT, PROVE A NEW TRANSACTION

Delete the fault, run a brand-new refresh and login, then prove expired leases are absent. A timed-out provider request is never replayed.

EVIDENCE: post-chaos sign-in + clean lease state
