[01]

SERVER-OWNED
TOKENS

The browser holds only a short-lived, hardened BIS cookie. Refresh tokens, PKCE verifiers, and provider exchanges remain inside the BFF.

[02]

EXPLICIT
OUTAGE POLICY

Only approved local-session routes may continue during provider loss. New login, refresh, and fresh-assurance actions return bounded availability errors.

[03]

SERIALIZED
REFRESH

Every rotation is a database-coordinated lease transaction. Multiple tabs and replicas cannot replay or race a single token chain.

BOUNDARY: A session is never extended because a browser retried; it is extended only after the BFF verifies, leases, rotates, and records the event.
