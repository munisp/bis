# Legacy React Native Client — Deprecated

`bis-mobile/` is the **authoritative BIS native application**. It is the supported Expo Router client for new functionality, security review, device validation, and release promotion.

This directory is retained temporarily for forensic continuity and migration reference only. Do not add features, release new builds, or point production distribution at this client. All new mobile UX, backend-contract, secure-session, and evidence-custody work must target `../bis-mobile`.

Removal requires an approved migration record confirming that supported user cohorts have transitioned and that offline evidence queues have been reconciled. Until then, this directory is not a supported production client.
